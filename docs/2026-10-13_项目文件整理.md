## 文件保留理由

- 采集后端、隔离雷达启动和时间探针：录包直接依赖。
- LIO 离线后端、bag 合并、里程计分析、性能监测：地图生成及质量检查依赖。
- RGB-D 数据库生成、验证和可视化：视觉地图工具链；不是相机2完整建图方案。
- 导航桥接、里程计 TF、RViz 点云转发、结果通知：导航启动直接依赖。
- select_patrol_waypoints.py：离线选点工具，仍可用于准备多点路线。
- tests/：相机选择、巡航协议、授权提示与转向配置回归测试。
- tools/sync_jetson_time.py：仅在导航/采集停止后按需使用，不能自动定期执行。
- 地图、视觉数据库、标定、ROS 源码、历史日志：不在本次删除范围。

清理的 `scripts/__pycache__` 是 Python 自动生成缓存，可重新生成；修改前已备份。

## 当前常用命令

全部在虚拟机项目根目录执行：

```bash
cd /home/duyipei/Lite3_Projects/lite3_patrol_project

# 室外/室内采集，二选一；按提示选择相机
bash scripts/outdoor_lidar_visual_mapping.sh start
bash scripts/indoor_lidar_visual_mapping.sh start
```

建图完整流程与相机2限制见 [建图采集操作说明](建图采集操作说明.md)。

已有室外地图导航（不是执行后立即运动）：

```bash
LITE3_VISUAL_MAP_ID=outdoor_20260921_003 \
LITE3_VISUAL_SEARCH_STRATEGY=startup_then_global \
bash scripts/navigation_start.sh start outdoor_20260921_003_area_review
```

多点巡航仍使用原入口；现场保护就绪，导航 READY 且 DISARMED 后才执行并确认 ARM：

```bash
bash scripts/patrol_route.sh run outdoor_20260921_003_area_review mission_recovered_20261008.yaml
```

离线回归（不连接机器人）：

```bash
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -p 'test_*.py'
```
