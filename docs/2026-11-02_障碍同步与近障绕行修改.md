# Lite3 障碍同步与近障绕行修改

本轮针对障碍出现后规划反应滞后、贴近障碍后持续顶着目标、窄通道受规划余量影响的问题。地图为 `patrol_map_20261031_01_area_v2_review`，定位仍为 XFeat＋LighterGlue 初始化及原 NDT/腿部里程计。启动默认 DISARMED，不自动发送目标。

2026-11-02 后续按用户要求删除速度门内的本地栅格停车功能。本次只修改并同步代码，不启动导航、ARM 或实机测试。修改前源码备份为 `results/remove_local_grid_20261102_194245/source_before.tar.gz`。原厂 VOA 高程栅格仍负责感知与投影；Nav2 的局部代价地图也继续保留。

## 障碍同步

1. 删除速度门对 `/patrol/voa/grid_map` 的直接订阅、`LocalGridSafety`、0.25 秒源年龄限制、未知格扫掠停车、制动包络、连续三帧放行及 `/patrol/voa/local_safety` 诊断。启动器不再传入本地栅格参数或为速度门加载 grid_map 环境。
2. 原厂 VOA → 投影桥 → 全局/局部代价地图 → NavFn/DWB → 速度门的链路保留。速度门不再直接根据高程栅格决定减速或停车；Factory Only 的障碍碰撞判断由 Nav2 完成。
3. 投影桥不再用大锁包住整个投影。新栅格、定位与 TF 可以并行接收；重复定时器不等待正在执行的投影，避免占满两个执行线程。
4. Factory Only 向 STVL 提供专用 `patrol_voa_costmap_origin`。XY/朝向来自本次投影所用的真实或有界腿部补偿位姿，时间戳与云一致；Z=0.5 与二维标记云一致。它是二维标记参考，不能用于物理外参、真实高度或相机投影，也不修改 NDT 的 TF。
5. 速度门仍订阅实际 `/local_costmap/costmap_raw`，检查机器人附近 1 m 内的已投影障碍是否在局部代价地图中有对应 lethal 格。缺少对应时先零速等待；不制造消费心跳、不清除障碍。已有静态 lethal 格也算已表示，因此这是空间对应检查，不是插件来源证明。该检查已解除对本地栅格停车模块的依赖，仍检查投影与代价地图的有效期。

选择 raw 格式的原因：Foxy 上游 `OccupancyGrid` 可视化消息使用零时间戳，也可能只发局部更新；raw 格式提供完整原生代价和节点时钟时间戳。代码将传感器单调时钟与 Nav2 ROS 时钟分开检查。[Foxy 发布器源码](https://raw.githubusercontent.com/ros-navigation/navigation2/foxy-devel/nav2_costmap_2d/src/costmap_2d_publisher.cpp)

专用标记参考解决的是 STVL 对 cloud 同时刻 sensor_frame 的再次查询，不是用最新位姿套旧点云。缺少可信定位/腿部数据仍不发布有效新投影。[STVL Foxy 观测缓冲源码](https://raw.githubusercontent.com/SteveMacenski/spatio_temporal_voxel_layer/foxy-devel/src/measurement_buffer.cpp)

## 贴近障碍时的处理

- 已投影障碍尚未在局部代价地图中表示：速度门先零速等待同步。
- 障碍已经进入代价地图：由 NavFn/DWB 根据实际足迹规划和检查轨迹；无可行轨迹时停车、等待或重规划。
- 删除本地栅格逻辑后，不再有该层的未知区域停车或接触障碍专用状态。此修改没有补齐相机近场观测，也不能证明贴障脱困已经通过验收。
- 最终目标朝向、真实足迹、终点净空检查和 Factory Only 禁止倒车的设置保持不变。

Factory Only 的无进展时间由原 v2 的 45 秒改为 15 秒：持续不动时更早进入现有等待/重规划流程。行为树仍是每秒重规划、等待 3 秒、最多 8 次恢复；没有加 spin/back_up，也不会为继续运动清空代价地图。该时间需验证 90° 转向实际耗时，尚未证明根治 180° 振荡。

本地停车诊断已删除；保留 `/patrol/gate_state` 中的代价地图同步等待状态和现有故障原因。只读探针保留感知、投影、代价地图时序及空间对应统计，不再模拟本地运动指令。

## 窄路通行

统一参数仍在 `navigation/obstacle_response.yaml`：

| 参数 | 本轮候选 |
|---|---:|
| 局部、全局规划膨胀 | 0.50 m，原本轮前为 0.55 m |
| cost scaling | 保持 10.0 |
| 局部更新 / 全局更新 | 保持 5 Hz / 2 Hz |
| 实际地图对外发布 | 2 Hz |
| 速度门直接读取本地栅格 | 已删除，不再有该层 0.25 s 限制 |
| 投影源年龄保护 | 保持原 0.5 s 门控及桥接 0.35 s 发布上限 |
| 局部 raw costmap 年龄 | 最多 0.75 s，针对 2 Hz 完整图发布 |
| 原生代价对应误差 | 最多 0.04 m，仅覆盖体素量化误差 |

真实足迹、padding、障碍高度门槛保持不变。规划膨胀是软代价范围，不等于实际必须离障碍 0.50 m；静态地图自身预膨胀和机器人真实尺寸仍可能使某些通道不可通过。

此前本地停车模块的合成通道测试属于已删除功能的历史结果，不作为当前版本的验收依据。删除该功能后尚未进行实机通行或避障验收。

在相机确实能看到的位置放入、移走软箱体，验证近场点进入 raw costmap，投影与地图未对应时门保持零速，障碍移除后原有占用正常衰减。不要通过清图、重贴时间戳或旁路停车使结果通过。

定位、近场覆盖和静止同步均通过后，先录包再人工 ARM 做运动：

```bash
bash scripts/record_avoidance_test.sh results/soft_box_test_$(date +%Y%m%d_%H%M%S) 300
```

顺序为远处软障碍停车 → 留宽通路绕行 → 完全封路等待 → 移除后恢复 → 较窄直通道 → 有转弯的通道 → 多点巡航。每步核对实际最小净空、停止距离、源年龄及未同步次数。贴近足迹、后方未知或近场仍盲时，不做自主脱困。

本轮没有授权脚本自动 ARM。原厂相机服务、NDT 参数、外参高度常量、静态地图及巡航点没有在本轮更换。
