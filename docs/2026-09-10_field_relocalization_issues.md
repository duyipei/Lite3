## 一键检查脚本

在宿主机执行：

```bash
cd /home/duyipei/Lite3_Projects/lite3_patrol_project
./scripts/field_relocalization_check.sh
```

默认检查地图：

```text
site_fusion_20260909_001_area_v4_review
```

指定其他地图：

```bash
./scripts/field_relocalization_check.sh 地图目录名
```

脚本会在一次 12 秒采样中输出 `[PASS]`、`[WARN]`、`[FAIL]`，检查以下内容：

- SSH、地图文件、Jetson 剩余空间、Realsense 服务；
- 相机、Mid360、IMU、视觉位姿、NDT 里程计的频率和最大断流；
- `localization_ready` 是否持续为真；
- NDT 位姿是否在地图边界内、是否跳变、停稳时是否漂移；
- `map -> base_link` 是否在地图内；
- NDT 收敛率、匹配误差和内点率；
- 两个底盘速度话题是否仍无发布者。

该脚本是**只读安全检查**：不会启动 Nav2、不会注入初始位姿、不会发布速度。显示 `FAIL` 时禁止发送目标点。

## 下一步必须完成

1. 在 `hdl_localization` 中拒绝不收敛、低内点率或超大位移的 NDT 更新，不能把异常结果继续发布成 `/odom` 和 TF。
2. 修改视觉初始化守卫：定位越界、里程计断流或单帧跳变时，立即把 `localization_ready` 置为 `false`。
3. 机器狗静止做至少 5~10 分钟测试；一键检查持续通过后，才重新启动隔离 Nav2 做路径预检。
4. 路径预检成功后，再由现场人员确认道路净空、手持官方遥控器，进行低速短距离 A→B 测试。

目前不应跳过第 1~3 步直接巡航。
