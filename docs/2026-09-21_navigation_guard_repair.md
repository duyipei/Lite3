# 2026-09-21 视觉导航集成修复

## 已修改

- 视觉守卫订阅 `/status`，在新的、未过期的 NDT 扫描到达时发布
  `/patrol/lidar_heartbeat`，替代已退出启动链的 manual_ndt_guard。
- 初始化只统计 `/status` 与 `/odom` 时间戳相同、本次 `/initialpose`
  发布之后的有效扫描。要求 NDT 接受匹配、匹配误差有限且不超过配置、
  有内点、腿里程计更新、位姿在地图边界和视觉粗定位窗口内。
  当前 C++ 补丁把未完成重锚和拒绝的匹配标为 `has_converged=false`。
- 运行中持续监测匹配失败、NDT 状态中断、腿里程计中断和位姿异常；
  失败锁存，需停止会话并重新初始化。CLEAR 只清速度门故障。
- 去除重复/旧时间戳样本的确认作用；保留视觉粗候选协方差下限，
  不把重复返回起点锚点当作更精确的几何测量。
- ARMED 时拒绝视觉初始化/重置请求。
- 速度门检查 READY 心跳超时。速度指令超时独立设为 0.5 秒，超时先
  输出零速，原有规划/恢复等待期限结束后再锁存故障；拒绝非有限速度。
- 当前室内地图的 STVL 传感器原点改为 `rslidar`。对已经降采样的
  `/aligned_points` 仅做高度过滤；不再做 0.15 m 两点体素过滤。
  观测缓存改为只保留最新帧、读取后清空，体素衰减设为 1 秒，
  与 2 Hz 地图更新周期配合。参数生成器同步更新。

## 验证

本地回调回归测试（替换 ROS 传输层，执行实际节点回调，不启动 DDS）：

```bash
python3 scripts/test_navigation_safety.py
```

包含初值预测不能放行、匹配失败、回调先后顺序、时间戳不匹配、重复帧、
旧帧、错误坐标系、传感器断流、协方差保留、守卫退出、残留指令和 NaN。

已有 ROS_DOMAIN_ID=77 冒烟测试已同步修改：先验证仅有初值里程计不会
READY，再发送真实消息类型的合成 NDT 状态和腿里程计，最后验证跳变撤销。
该测试仍需在带有 Foxy 和 hdl_localization 消息包的 Jetson 上执行。

尚未接入独立高密度避障点云或启用自体裁剪；当前仍使用 NDT 降采样输出，

不能用扩大近场删除范围或提高最低障碍高度来隐藏真实障碍。

网络恢复后可先用主脚本 `install` 同步修复，再运行隔离冒烟测试及
无运动视觉定位测试；通过点云/TF 实测复核后再进行导航测试。
